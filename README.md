# Siraj
An Islamic prayers application. Siraj displays and notifies of prayer times for different parts in the world.

## Overview

<p align="center">
		<img src="https://store-images.s-microsoft.com/image/apps.59093.13837622056252294.4274167e-c30d-492f-b835-78e3b5689d7e.d9134999-1133-4f37-9136-399c66a42349"/>
</p>

* Runs at start up and stays on the tray icon 
* Modern UX/UI that adheres to Windows guidelines
* Features an asy to use Tasbih counting interface
* Native and light by using WinUI 3's AOT capabilities
* Notifies of prayer times and plays Athan voices on time
* Comes with lots of configurable settings like Athan voice and themes
* Automatically gets your location on permission and features manually searching
